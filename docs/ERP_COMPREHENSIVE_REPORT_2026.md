## 1. ملخص النظام العام

### 1.1 وصف النظام

نظام **Pharmacy ERP** هو نظام متكامل لإدارة موارد الصيدلية مبني بتقنيات حديثة (React + TypeScript + Supabase). يهدف النظام إلى توفير حل شامل يغطي جميع العمليات التجارية والمالية واللوجستية للصيدلية.

### 1.2 إحصائيات النظام

| المكون | العدد |
|--------|-------|
| **جداول قاعدة البيانات** | ~132 جدول |
| **صفحات التطبيق** | ~100 صفحة |
| **دوال قاعدة البيانات (RPC)** | 156 دالة |
| **سياسات الأمان (RLS)** | 50+ سياسة |
| **Edge Functions** | 3 دوال |
| **مكونات React** | ~70 مكون قابل لإعادة الاستخدام |
| **ملفات الترحيل (Migrations)** | ~115 ملف |

### 1.3 التقنيات المستخدمة

| الطبقة | التقنية | الإصدار |
|--------|---------|---------|
| **Frontend** | React + TypeScript | 18.3.1 |
| **Styling** | Tailwind CSS + Shadcn/UI | 3.4.17 |
| **Build Tool** | Vite | 5.4.19 |
| **State Management** | TanStack React Query | 5.83.0 |
| **Backend** | Supabase (PostgreSQL) | - |
| **Forms** | React Hook Form + Zod | 7.61.1 |
| **Charts** | Recharts | 2.15.4 |

### 1.4 العملة الأساسية

- **الريال اليمني (YER)** هو العملة الأساسية للنظام
- دعم كامل للعملات الأجنبية (SAR، USD، EUR، وغيرها)
- جميع القيود المحاسبية تُخزن بقيمتين: FC (العملة الأجنبية) و BC (العملة الأساسية)
- جميع التقارير المالية والأرصدة المجمعة بالريال اليمني

## 7. تحديث 2026-01-31: تطبيق القواعد الصارمة للـ ERP

### 7.1 القواعد الذهبية المُطبقة على مستوى قاعدة البيانات

#### ✅ قاعدة المخزون الذهبية (Inventory Golden Rule)

| القاعدة | الحالة | الـ Trigger |
|---------|--------|-------------|
| المنتج يبدأ بكمية = 0 | ✅ مُطبق | `trg_enforce_product_zero_quantity` |
| منع تعديل الكمية مباشرة | ✅ مُطبق | `trg_absolute_stock_protection` |
| منع حذف سجلات المخزون | ✅ مُطبق | Trigger blocks DELETE |

#### ✅ المستندات المسموح بها لتغيير المخزون

| المستند | الدالة المسؤولة |
|---------|-----------------|
| فاتورة الشراء | `post_purchase_invoice` |
| فاتورة البيع | `post_sales_invoice` |
| مرتجع الشراء | `post_purchase_return` |
| مرتجع البيع | `post_sales_return` |
| تسوية المخزون | `post_stock_adjustment` |
| استلام البضاعة | `post_goods_receipt` |

#### ✅ دورة المشتريات الإلزامية (Mandatory Procurement Chain)

```
PR → RFQ → PO → GRN → PI
```

| القيد | الـ Trigger |
|-------|------------|
| RFQ يتطلب PR | `trg_enforce_rfq_requires_pr` |
| PO يتطلب RFQ أو PR | `trg_enforce_po_requires_rfq` |
| GRN يتطلب PO | `trg_enforce_grn_requires_po` |
| PI يتطلب PO أو GRN | `trg_enforce_pi_requires_source` |

#### ✅ عدم قابلية التعديل للمستندات (Document Immutability)

- ❌ لا تعديل بعد الترحيل
- ❌ لا حذف بعد الترحيل  
- ❌ لا إلغاء بعد الترحيل → يتطلب إنشاء مرتجع منفصل

**Trigger:** `enforce_document_immutability()`

#### ✅ نظام الحجز والقفل (Stock Reservation)

| مستوى المخزون | العمود |
|---------------|--------|
| الكمية الكلية | `qty_on_hand` |
| الكمية المحجوزة | `qty_reserved` |
| الكمية المتاحة | كلية - محجوزة |
| الكمية في الطريق | `qty_inbound` |

**View للعرض:** `v_stock_levels`

#### ✅ حقل تنبيه الصلاحية

| الحقل | النوع | الوصف |
|-------|-------|-------|
| `expiry_alert_months` | INTEGER | عدد الأشهر للتنبيه (اختياري) |

**View للتنبيهات:** `v_expiry_alerts`
